# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-08

### Added
- OpenCode Adapter Layer with event normalization
- Internal Event Bus for subsystem communication
- Journal/Storage for persistent evidence layer
- Deterministic Reflection Engine (friction, elegance, honesty, unseen layer)
- Learning Pipeline: Trajectory → Pattern Detection → Improvement Proposals → Promotion
- Evaluation Harness: Baseline → Experiment → Comparison → Decision
- Safe Execution Isolation using Git worktrees
- Model Routing / Agent Delegation with capability-based profiles
- Routing Memory for outcome-informed future decisions
- Configuration schema with YAML support
- Default agent profiles: architect, worker, reviewer
- Sandbox execution with policy enforcement

### Architecture Decisions
- Plugin as cognitive runtime, not skill injector
- Filesystem as source of truth for all state
- Deterministic reflection first, LLM-enhanced later
- Git worktrees for experiment isolation
- Capability-based routing, not model-name routing
- Evaluation gates before any promotion
- Human approval gate for autonomous promotion
